# Linawa — Democratic Engagement Platform for Civic Participation

**🏅 Top 15 Finalist — UPV Komsai Hackathon 2025**  
Hosted by UP Visayas

## 🌱 About Linawa
Linawa (meaning “clarity” in Hiligaynon) is a digital civic engagement platform. It empowers citizens to voice concerns, participate in local governance, and promote transparency by bridging feedback channels with local leaders and civic groups.

## 💡 Core Features
- Canididates transparency, list of their advocacies, party list, and education
- Real-time report issue feature where user can report election misconducts and unethical behaviour
- Real-time news update realted to the current election news
- Citizen petition forms where citizens are encouraged to let their voice be heard
- Mock election to have a better grasp of the favourable candidates

## 🔧 Technologies Used
- Node.js / Express.js (Backend)
- Firebase Firestore (Database)
- React + Vite (Frontend)
- Python (AI Implementation)

## 🔌APIs & Integration

-  Google News API
